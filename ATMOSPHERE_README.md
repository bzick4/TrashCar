# Атмосфера в духе Over the Hill

Распакуй поверх проекта (папка `Assets` совпадает). Сделано от версии TrashCar из GitHub от 17.11.

## Что внутри
**Новое**
- `Shaders/Atmosphere.shader` + `AtmosphereCommon.hlsl` — воздушная дымка постэффектом по глубине.
  Ложится на всё одинаково (Toon Shaders Pro, URP Lit, свои шейдеры): дальнее тает в цвете горизонта слоями.
- `Shaders/SkyGradient.shader` — небо-градиент в тех же цветах, мягкое солнце с ореолом.
- `Shaders/ToonTerrain.shader` + `ToonTerrainInput.hlsl` — рельеф без текстур: трава / сухая трава пятнами /
  камень на склонах / снег на вершинах, свет и цветная тень как у моделей.
- `Scripts/World/Atmosphere/StylizedAtmosphere.cs` — палитра и дымка. Пресеты: Золотой час, Полдень, Пасмурно.
- `Scripts/World/Atmosphere/BackdropHills.cs` — гряды холмов вокруг трассы до 2 км и лес на склонах
  (GPU instancing, ~2600 ёлок без GameObject'ов). Без коллайдеров, по сиду трассы — у всех игроков одинаково.
- `Editor/AtmosphereBuilder.cs` — меню **JunkRace → Атмосфера: применить к открытой сцене**.

**Изменены (заменяют твои файлы — если правил их локально, сравни)**
- `Scripts/World/Route/RouteGenerator.cs` — 3 вставки: задник после раскладки свалки, после постройки трассы,
  и дальность деревьев/мелочи берётся из атмосферы (деревья тают в дымке, а не выскакивают).
- `Editor/TestSceneBuilder.cs` — 1 строка: при сборке трассы вызывается AtmosphereBuilder.

## Как включить
1. Распаковать, дождаться компиляции.
2. **JunkRace → Собрать всё** (или открыть трассу и **JunkRace → Атмосфера: применить к открытой сцене**).
   Создаются материалы в `Assets/JunkRace/Settings` (JR_Atmosphere, JR_SkyGradient, JR_ToonTerrain, JR_Tree*),
   в рендереры PC/Mobile добавляется фича **«Атмосфера (дымка)»** (Full Screen Pass), в сцену — объект **Атмосфера**.
3. Play. Холмы строятся в игре по сиду. Посмотреть в редакторе: ПКМ по компоненту BackdropHills →
   «Предпросмотр: построить вокруг прямой дороги».

## Что крутить
- **Атмосфера → Пресет** — палитра целиком. Цвета можно править руками.
- **Половина дымки** (340 м) — меньше = туманнее. **Максимум** (0.93) — насколько горы тают у горизонта.
- **Дымка по высоте** — в низинах гуще, вершины чище (слои силуэтов).
- **Дальность деревьев** у дороги (320 м) и мелочи (110 м) — компромисс красоты и FPS.
- **Холмы-задник**: где начинаются (90 м от дороги — ближе нельзя, закопаются декорации), высоты ближних/дальних,
  размер холмов, шаг гряд, число деревьев, тени от деревьев (выкл — дорого).
- **JR_ToonTerrain** — цвета травы/камня/снега, наклон камня, высота снега, гранёность (0 — гладко, 1 — low-poly).

## Если что-то не так
- Нет дымки → проверь, что в PC_Renderer есть включённая фича «Атмосфера (дымка)» и на сцене есть объект Атмосфера.
- Дымка вверх ногами (маловероятно) → напиши, поправлю одну строку в Atmosphere.shader.
- Хочешь вернуть как было → **JunkRace → Атмосфера: убрать дымку из рендереров** и удали объект Атмосфера.
