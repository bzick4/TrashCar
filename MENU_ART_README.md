# Арт меню JunkRace

Распакуй поверх проекта (папка `Assets/` совпадает с проектом):
- `Assets/JunkRace/Resources/UI/` — нарезанные спрайты: кнопки (4 состояния), панель, строки, поле ввода, бирка, иконки, логотип, фон.
- `Assets/JunkRace/Scripts/UI/MainMenu.cs`, `InGameMenu.cs` — **заменяют** текущие (сделаны из версии в репо от 17.11).
- `Assets/JunkRace/Editor/MenuUiImporter.cs` — сам ставит правильный импорт картинкам из Resources/UI
  (Editor GUI, без мипмапов и сжатия). Если картинки уже были импортированы раньше — ПКМ по папке UI → Reimport.

Как устроено:
- IMGUI остался, логика экранов та же. Поменялись только стили (`MenuStyles`) и разметка.
- Кнопки и панели растягиваются по 9-slice через `GUIStyle.border`. Размеры картинок подогнаны под 1080p.
- Если папки UI нет — меню выглядит как раньше (однотонное), ничего не ломается.
- Новое: логотип, фон-арт, иконки на кнопках, корона хоста, значки готов/не готов, замок у серверов с паролем,
  бирка с кодом и кнопка «Копировать».

## Анимированные иконки (MenuIconFx.cs) — на DOTween

**Сначала поставь DOTween**, иначе проект не соберётся:
1. Asset Store → «DOTween (HOTween v2)» (бесплатный) → Add to My Assets.
2. Unity: Window → Package Manager → My Assets → DOTween → Download → Import.
3. Откроется DOTween Utility Panel (или Tools → Demigiant → DOTween Utility Panel) → **Setup DOTween...** → Apply.

Что делает:
- **Соло — колесо:** наведение — раскручивается (OutQuad), отвёл — катится по инерции и останавливается;
  нажатие — разгон + сплющивание в овал с пружинкой (OutBack) + тряска (DOTween.Shake), из-под колеса грязь и пыль.
  Через 0.8 с запускается соло.
- **Кооп — куча:** наведение — «дышит» (Yoyo-петля) и по одной выплёвывает детали;
  нажатие — вспучивается, выбрасывает 16 деталей с пылью и оседает с подпрыгиванием (OutBounce).
  Через 0.85 с открывается список серверов.

Как устроено:
- DOTween крутит состояния иконок (скорость, сплющивание, тряска, оседание, задержка перед переходом — Sequence с колбэком).
- Летящие частицы — простой цикл с гравитацией в Update: на сотни коротких частиц это дешевле, чем твин на каждую.
- Все твины SetUpdate(true) — работают и на паузе. Твины убиваются при уходе с экрана и при уничтожении меню.
- Пока играет анимация нажатия, остальные нажатия игнорируются.
- Что крутить — константы в начале `MenuIconFx.cs` и Ease в LaunchWheel / LaunchPile.
- Картинки: `Resources/UI/Anim/`. Если их нет — меню работает без анимаций.
