# JunkRace — прототип, этап 2 (общий мир по сети)

Собери машину из хлама на свалке и доедь до финиша. Один или до 4 человек в одном мире.

## Требования
- **Unity 6**
- Пакеты: **Input System**, **Netcode for GameObjects**, **Multiplayer Services** (`com.unity.services.multiplayer`)
- Project Settings → Player → Active Input Handling = **Input System Package (New)**
- Проект привязан к Unity Cloud: Edit → Project Settings → **Services** → выбрать/создать проект
  (Sessions работают на Lobby + Relay; как в CarDerby)
- URP или Built-in — без разницы

## Установка
1. Скопируй папку `JunkRace` в `Assets/`.
2. Меню **JunkRace → Собрать всё (меню + трасса)**. Обе сцены попадут в Build Settings, откроется меню.
3. Play.

## Меню
- **Соло** — сразу на трассу, без сети.
- **Кооп** — имя игрока → список серверов (обновляется сам) → войти (с паролем, если есть), войти по коду
  или создать свой: название + пароль (необязателен; если есть — от 8 символов, это требование Unity).
  Лобби до 4 игроков: когда все 4 в сборе — отсчёт 3 сек и старт. Хост может нажать «Начать сейчас (тест)».
  Игра через интернет идёт через Relay: никаких IP и проброса портов.
- **Ультра кооп** — закрыт.
- В игре **Esc / Start** — пауза: продолжить, заново (соло), в меню.

### Как тестировать кооп на одном компе
Window → Multiplayer → **Multiplayer Play Mode**: включи 1–3 виртуальных игрока.
Каждая копия входит в сервисы под своим анонимным профилем, так что это разные игроки.
В одной создай сервер, в другой он появится в списке.

## Как устроена сеть
- **Хост — авторитет.** Только он считает физику, проверяет действия и решает, что отвалилось.
- **Клиент шлёт намерения**: «хочу взять эту деталь», «прикрути сюда», «сажусь», газ/руль 20 раз в секунду.
- **Хост рассылает**: позиции машин и незакреплённых деталей (20 Гц, только то, что двигается, плюс понемногу спящих),
  позиции игроков, события (взял / прикрутил / отвалилось / сел / финиш), а новичку — полное состояние.
- Прикрученные детали не синхронизируются отдельно: едут вместе с машиной.
- Детали — обычные объекты сцены, их номер = место в иерархии. Ни NetworkObject, ни сетевых префабов не нужно.
- Ходьбу каждый считает сам у себя (отзывчиво), хосту шлёт позицию.

## Управление
| | Клавиатура | Геймпад |
|---|---|---|
| Ходить | WASD | левый стик |
| Камера | мышь | правый стик |
| Прыжок | Space | A / ✕ |
| Взять / бросить / прикрутить | E | X / □ |
| Сесть / выйти | F | Y / △ |
| Газ / тормоз | W / S | правый / левый триггер |
| Руль | A / D | левый стик |
| Спец (зонт, пылесос) | Space | A / ✕ |
| Перевернуть машину | R | Select |
| Характеристики машины | Tab | крестовина вверх |

Смотришь на деталь или держишь её — справа карточка: что это и как изменится машина (скорость, разгон, вес, плавучесть).
Несёшь деталь к корпусу — у свободной точки появляется шарик, жмёшь E, деталь прилипает.

## Трасса
Свалка → трамплин → бассейн → выезд → финиш.
- Чтобы ехать на колёсах, нужен **мотор** (газонокосилка, стиралка, бензопила). Без мотора колёса просто катятся.
- На колёсах бассейн не переплыть: нужна **ванна** (плавает) и **вентилятор** или **пылесос**.
- Паллет тонет, но колёса едут по дну. Это не баг, это фича.
- Колёса поворачивают, только если на машине есть **руль**.
- Сильный удар отрывает детали. Отвалилось — подбери и прикрути обратно.

## Архитектура
- `IPartInput` — **кто управляет** деталью: игрок, бот, автораскладка. Деталь не знает, кто.
- `Authority` — **кто решает**, что произошло. Офлайн и на хосте `true`, у клиента `false`.
- `World` — единая точка изменений: `Request*` (хочу) → `Server*` (проверка на хосте) → `Apply*` (применить везде).
- `Vehicle` — один `Rigidbody` на всю машину, детали = составной коллайдер.
  Отрыв считается только на авторитете и выполняется в `FixedUpdate`.
- `Part.InputOverride` — задел под кооп «каждый на своей детали».
- `Vehicle.TeamId` — задел под командный режим.

## Что крутить, если «не смешно»
- `Part.breakImpulse` — как легко всё разваливается.
- `WheelPart`: `spring`, `damper`, `grip` (занос), `traction` (разгон).
- `EnginePart.power` — мощность мотора (Вт, 1 л.с. ≈ 735 Вт).
- `Vehicle.centerOfMassOffset` — как часто кувыркается.
- `ThrusterPart.thrust` — насколько безумны вентиляторы.
