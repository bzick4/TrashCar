# Звук JunkRace

## Музыка — `Music/`
Кладите файлы (mp3, ogg, wav) в подпапки:
- `Menu/` — главное меню;
- `Yard/` — сборка машины на свалке;
- `Race/` — гонка (отсчёт, заезд, результаты).

Треки играют по кругу в случайном порядке, между треками и экранами — плавный переход.
Пустая папка — играет музыка из любой другой. Код менять не нужно.

**Имя файла = подпись на плашке «сейчас играет»** (слева вверху при каждом новом треке):
`Исполнитель - Название.mp3` → две строки, название и исполнитель. Без « - » — только название.
Подчёркивания в имени показываются пробелами.

**Папка `Music/` не попадает в git** (см. `.gitignore`): песни без лицензии нельзя выкладывать
в публичный репозиторий. В сборку игры они попадают — такую сборку давайте только друзьям лично.
Перед публикацией замените на музыку с лицензией (Pixabay Music, incompetech.com, OpenGameArt CC0).

## Мотор — `Engine/`
Зацикленный звук (1–3 секунды, ровный, без начала и конца). Имя файла — какой мотор:
- `engine_mower` — мотор газонокосилки;
- `engine_washer` — мотор от стиралки;
- `engine_electric` — электромотор;
- `engine_chainsaw` — бензопила;
- `engine` — для всех остальных и если нужного файла нет.

Нет ни одного файла — играет встроенная заглушка. Высоту и громкость игра меняет сама по газу и скорости.
Бесплатные звуки: freesound.org (лицензия CC0).
