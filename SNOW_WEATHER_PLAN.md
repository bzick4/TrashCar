## Что хочет пользователь
1. **Снежный биом**: снежная дорога, рядом снежные горы, деревья в снегу.
2. **Следы от колёс** на дорогах.
3. **Погода**: метель/снег, дождь, ветер — для красоты. Решение: по биому + случайно по сиду (у всех игроков одинаково). Снег/метель в снежном биоме; в лесу и горах иногда дождь или ветер с листьями.
4. Пустыня — **позже**, отдельным шагом. Вода «нуждается в ужасной доработке» — тоже потом.

Текстуры снега: сделать самим (перекрасить горные `Assets/Prefab/Route/Textures/mountain_*.png` в снежные: белый, голубые тени, колея), пользователь потом пришлёт свои картинки на замену.

## Как устроено (что найдено)
- `Assets/JunkRace/Scripts/World/Route/RouteMap.cs`: `enum Biome { Forest, Mountains }`, у каждой точки `RouteSample.Biome`.
- `RouteGenerator.cs`:
  - `Generate()` — участки 3–4, биомы чередуются (`b == Forest ? Mountains : Forest`), `BuildForest`/`BuildMountains`, названия для `Summary`.
  - Меш дороги: сабмеши `[биом*2]` верх, `[биом*2+1]` откосы (`BuildRoadMesh`, `EndCap`, `BuildForkFill` создают `new List<int>[4]`; `FinishRoadMesh` ставит 4 материала `roadForest/sideForest/roadMountain/sideMountain`). Для нового биома — расширить до 6 и добавить `roadSnow/sideSnow`.
  - Земля — одна большая плита травы (`BuildGround` → `GroundStrip`/`GroundPiece`, `groundGrass`, полосы по z между реками). Для снега нужна снежная земля вокруг снежного участка (например, полосы по z, как у рек, или отдельные плиты по участку).
  - Декор: `Decorate()` → `DecorateForest`/`DecorateMountains`; ёлки `Pine()`, горы `mountainModels` (уже со снежными шапками), камни `rockModels`.
  - Поля моделей/материалов заполняет сборщик сцены (`TestSceneBuilder`, меню «JunkRace → Собрать всё» — только с разрешения).
  - `ApplySun()` — солнце по сиду.
- Пыль из-под колёс: `Assets/JunkRace/Scripts/Parts/WheelDust.cs` (две общие системы частиц), вызывается из `WheelPart.KickDust(bool grounded, RaycastHit hit)` — оттуда же брать точку контакта для следов.
- Дымка/туман: `Assets/JunkRace/Scripts/World/Atmosphere/StylizedAtmosphere.cs` (можно менять цвет дымки в снегу/дожде), холмы-задник `BackdropHills.cs`.
